# Alexandria Reimagined — Technical Prototype

This repository contains the Python-based technical prototype developed for the 
Interaction Design project *Alexandria Reimagined*. The prototype demonstrates 
a staged scroll-opening interaction using ASCII UI elements and timed animation.

## How it works
- Press ENTER once to begin the animation.
- The scroll transitions through four visual states:
  1. Closed
  2. Half-closed
  3. Half-open
  4. Fully open (revealing reconstructed text)

## Requirements
- Python 3.x
